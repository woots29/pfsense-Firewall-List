# pfSense Gateway per Interface Report

A simple, drop-in PHP snippet for **pfSense** that adds a real-time table showing:


| Interface (Alias)               | Gateways Used in Rules               |
|:-------------------------|:-----------------------------------------|
| **LAN (opt34)**  | GW_WAN1, (default)                  |
| **LAN2 (opt35)**             | GW_WAN1, GW_WAN3                       |


Displays **interface alias (logical name)** and **clean gateway names** — no more `"Interface X Gateway"` clutter.
